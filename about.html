About

PDF tools for everyday tasks

Thirteen Months PDF Tools brings common PDF tasks together at pdf.afeiii.com. You can merge, split, compress, edit and convert documents without creating an account.

How the tools work

The available tools are designed to process selected files in your browser. Some features download processing components or language data when you open them, so the first use may take longer. Check the result before sharing or deleting your original document.

Open-source foundation

This site is a customized deployment of BentoPDF. The upstream project and its contributors created the PDF toolkit. Our deployment, site content and changes are available in the Thirteen Months source repository under the project's AGPL-3.0 license.

Part of afeiii.com

The related Thirteen Months Toolbox focuses on developer and IT tools. This site focuses on PDF work. Questions or bug reports can be sent to support@afeiii.com.

关于本站

日常 PDF 处理工具

十三月 PDF 工具汇集了合并、拆分、压缩、编辑、格式转换等常用功能，访问 pdf.afeiii.com 即可使用，无需注册账号。

处理方式

本站提供的工具主要在浏览器中处理您选取的文件。部分功能在首次打开时需要下载处理组件或语言数据，因此可能稍慢。请在分享文件或删除原件前检查输出结果。
