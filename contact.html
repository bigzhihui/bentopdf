Contact

Get in touch

For a broken tool, accessibility issue, or suggestion, email support@afeiii.com.

Reporting a problem

Please include the tool's URL, your browser and device, the steps that led to the issue, and any error message. Avoid sending confidential documents or passwords by email. A description or a non-sensitive sample is usually enough to start investigating.

Source and issues

You can also review the site source and file a reproducible issue in its GitHub repository. For questions about the original BentoPDF project, use the upstream repository.

联系我们

反馈问题与建议

如遇工具故障、无障碍问题，或想提出建议，请发送邮件至 support@afeiii.com。

如何描述问题

请附上工具页面地址、浏览器与设备、触发问题的操作步骤和错误提示。不要通过邮件发送机密文件或密码；文字描述或不含敏感信息的样例通常就足以开始排查。

源码与问题反馈

您也可以在 本站源码仓库 查看代码并提交可复现的问题。若问题针对原版 BentoPDF，可前往 原项目仓库。
